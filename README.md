# For You 💕 — Romantic Galaxy Edition

## How to add "Best Part" (or any song)

1. Put your romantic song file inside the same folder as index.html
2. Rename it to:  **music.mp3**
3. Open index.html — the music will start on the first click/tap

Browsers do not allow silent autoplay, so the song begins as soon as she interacts with the page (Yes button or anywhere).
